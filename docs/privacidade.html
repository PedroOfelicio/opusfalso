Política de privacidade

Gadosso Edit · atualizada em 1º de novembro de 2026

O que é o app

O Gadosso Edit é um editor de vídeo de uso pessoal que roda no computador do próprio usuário. Não existe servidor on-line do app: nenhum dado é enviado para o autor nem para terceiros.

Dados do Google que o app acessa

Ao entrar com o Google, o app pede somente estas permissões de leitura:

  • youtube.readonly: nome do canal, número de inscritos, lista de vídeos e as estatísticas públicas de cada um (views, likes, comentários).
  • yt-analytics.readonly: relatórios do YouTube Analytics do canal (views por dia, tempo assistido, retenção, inscritos ganhos).

O app não publica, não altera e não apaga nada no YouTube nem na conta do Google, e não acessa e-mail, contatos ou outros serviços.

Como os dados são usados

Só para mostrar ao próprio usuário um painel com as métricas do canal dele e ligar cada vídeo publicado ao corte que o app gerou. Os dados não são vendidos, compartilhados nem usados para publicidade.

Onde os dados ficam

O token de acesso e as métricas ficam em arquivos na pasta de dados do app, no computador do usuário. As únicas conexões feitas são diretamente com as APIs do Google.

Como remover o acesso

  • No app: aba Métricas, botão “sair”, que apaga o token do computador.
  • Na conta do Google: myaccount.google.com/permissions, remover o acesso do Gadosso Edit.
  • Apagar a pasta de dados do app remove também as métricas guardadas.

Uso limitado

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado. O app também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.
